How to use Foldex

Foldex home / 日本語

Foldex gets you to the folder you need in Windows Open and Save dialogs, instantly. Click a recent or favorite folder and the dialog jumps straight there. The red frames and numbers in the pictures match the numbers in the text.

1. Start Foldex

  • Start Foldex from the Start menu. No window opens; an icon appears in the notification area (system tray)
  • Click the notification area icon to open the Foldex Window (section 7). Right-click it for "Show Foldex" and "Quit"
  • To start Foldex when you sign in, turn it on in Task Manager (Ctrl+Shift+Esc) under Startup apps (off by default)

2. The panel below the dialog

  • Open an Open or Save dialog in any app and the Foldex panel (1) appears right below it. It hides when the dialog closes
  • The tabs (2) switch between History, Favorites, Pattern, Settings and About
  • Click a folder in the panel and the dialog goes there
  • Hold Ctrl and turn the mouse wheel to change the text size
  • Foldex works with most apps, but the panel does not appear for apps that use their own custom dialogs (such as some Electron or Java applications)

3. History

No.PartWhat it does
1ListThe folder open when a dialog closed is recorded, newest first (up to 100). Click to go there
2All Apps / Per AppPer App shows only the folders used in the app that opened the current dialog
3FilterType to narrow the list on the spot. The ✕ at the right or Esc clears it
4⊗Removes that entry
  • Folders that no longer exist are shown dimmed. Clicking one asks whether to remove it

4. Favorites

No.PartWhat it does
1GroupClick to expand or collapse. The ★ of the folders in it takes the group's color
2✎Renames the group or changes its color (right-clicking the group does the same)
3↺ ↻Undo and redo
4+ GroupMakes a new group
5+ Current FolderAdds the folder the dialog is showing
6+ Add DirectoryAdds a folder by its path
  • You can also add folders by dragging them from File Explorer
  • Drag and drop to reorder. Drop on the middle of a group's header to put the folder into that group
  • Folders outside any group have a white ★. The ⊗ at the right end of a row removes it

Renaming a group and changing its color

  • Edit the name in the field (1). A color in the palette (2) applies as soon as you click it
  • Click anywhere outside that group's row to finish (Enter also finishes). Esc cancels and restores both the name and the color

5. Pattern

  • The path of the folder the dialog is showing is split into blocks (1), one per level
  • Under each block are the folders at that level (2). Click one to go there
  • Type in the search box (3) to narrow the candidates
  • Turn on "Number variants only" (4) to show only folders that differ by number, such as project_01 and project_02
  • A block lists up to 500 folders, in name order

6. Settings

Position

SettingBehavior
DialogFollows the dialog, right below it (the panel's default)

Bottom, Left, RightDocked to that edge of the screen
  • Ctrl+Alt+←, → and ↓ dock to the left, right and bottom; Ctrl+Alt+↑ returns to Dialog / Free. The panel moves when a dialog is open, the Foldex Window otherwise
  • With Dialog, drag the panel's bottom edge to resize it; when docked, drag the inner edge
  • Ctrl+Shift+F can clash with other apps' keys (VS Code, for example). If it does, change it in 6

7. The Foldex Window

  • A window you can use without a dialog. Show or hide it with the notification area icon or the shortcut key (Ctrl+Shift+F by default)
  • Clicking a folder opens it in File Explorer
  • In Favorites, ↺, ↻ and "+ Group" (1) are to the right of the filter box, and "+ Add Directory" (2) is to the right of the tabs
  • It is a normal window: drag it to move it, drag its edges to resize it
  • Position (1): Free, Bottom, Left or Right. Foldex remembers the Free position and size, and returns there when you switch back from a docked position
  • With "Close after opening a folder" (2) on (the default), the Foldex Window closes once a folder opens

8. About (trial and purchase)

  • During the Microsoft Store trial, the days left (1) and a Buy button (2) appear. Buy opens the Store's purchase dialog
  • The 30-day free trial includes every feature. When it ends, Foldex shows a message and exits
  • "Third-party software licenses" (3) shows the licenses of the software Foldex includes

9. Quit and uninstall

  • Quit: right-click the Foldex icon in the notification area → "Quit"
  • Uninstall: Settings → Apps → Installed apps, then "…" next to Foldex → Uninstall. Your history, favorites and settings are removed too

10. Troubleshooting

  • Cannot navigate dialogs of apps running as administrator: run Foldex as administrator too (right-click Foldex in the Start menu → More → Run as administrator). This is how Windows works (UIPI)
  • The panel does not appear: apps with their own custom dialogs are not supported. Foldex works with the standard Windows Open and Save dialogs
  • Flagged by antivirus software: a false positive, reported to Microsoft
  • Your history, favorites and settings stay on this PC and are never sent anywhere (only the Store license check talks to Microsoft). See the Privacy Policy
