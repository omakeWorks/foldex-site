How to use Foldex

Foldex gets you to the folder you need in Windows Open and Save dialogs, instantly. Click a recent or favorite folder and the dialog jumps straight there.

1Getting started (3 steps)

  1. Start Foldex from the Start menu. No window opens; an icon appears in the notification area (system tray)
  2. Open an Open or Save dialog in any app. The Foldex panel 1 appears right below it
  3. Click a folder in the panel and the dialog goes there
  • Folders you use are collected in History automatically. Add the ones you use often to Favorites
  • The tabs 2 switch between History, Favorites, Pattern, Settings and About
  • The red numbered dots in the pictures match the numbers in the text

2History

The folders you used in dialogs are listed automatically, newest first. Click one to go there.

No.PartWhat it does
1ListNewest first, up to 100. Click to go there
2All Apps / Per AppPer App shows only the folders used in the app that opened the current dialog
3FilterType to narrow the list. The ✕ or Esc clears it
4⊗Removes that entry
  • Folders the app that opened the current dialog used before have a yellow ▸ (in All Apps too). Per App lists only these yellow folders

3Favorites

Keep the folders you use often and reach them in one click. Color-coded groups keep them organized.

Adding folders

  • "+ Current Folder" 5: adds the folder the dialog is showing
  • "+ Add Directory" 6: adds a folder by its path
  • You can also drag folders in from File Explorer
  • A folder that is already there shows "Already in your favorites" (and the group it is in, if any)

Organizing

1GroupClick to expand or collapse. The ★ of the folders in it takes the group's color
2✎Renames the group or changes its color. You can also right-click the group to change its name and color
3↺ ↻Undo or redo changes such as adding, removing or moving items, and making or changing groups

  • Click anywhere else or press Enter to finish; Esc cancels

4Pattern

Go to another folder at the same level as the current one. Handy for moving between numbered folders, such as from project_01 to project_02.

  • The current path is split into blocks 1, one per level, with the folders at that level 2 under each. Click one to go there
  • Narrow the candidates with the search box 3. Turn on "Number variants only" 4 to show only folders that differ by number

5The Foldex Window

A window for when no dialog is open. Clicking a folder opens it in File Explorer.

  • Show or hide it: Ctrl+Shift+F. Clicking the Foldex icon in the notification area also shows it
  • History and Favorites work as in the panel. In Favorites, ↺, ↻ and "+ Group" 1 are to the right of the filter box, and "+ Add Directory" 2 is to the right of the tabs
  • Unlike the panel attached to Open and Save dialogs, it is a regular window: drag it to move it, drag its edges to resize it
  • Position 1: Free, Bottom, Left or Right. Foldex remembers the Free position and size, and returns there when you switch back from an edge
  • Close after opening a folder 2: when on (the default), the window closes once a folder opens

7Trial and purchase

  • The 30-day free trial includes every feature. During the trial, the About tab shows the days left 1 and a Buy button 2, which opens the Store's purchase dialog
  • When the trial ends, Foldex shows a message and exits
  • "Third-party software licenses" 3 shows the licenses of the software Foldex includes

8Auto-start, quit and uninstall

  • Auto-start: turn Foldex on in Task Manager (Ctrl+Shift+Esc) under Startup apps (off by default)
  • Quit: right-click the Foldex icon in the notification area → "Quit"
  • Uninstall: Settings → Apps → Installed apps, then "…" next to Foldex → Uninstall. Your history, favorites and settings are removed too

10Troubleshooting

  • The panel does not appear: some apps use their own custom dialogs (such as some Electron or Java applications). Foldex works with the standard Windows Open and Save dialogs
  • Cannot navigate dialogs of apps running as administrator: run Foldex as administrator too (right-click Foldex in the Start menu → More → Run as administrator). This is how Windows works (UIPI)
  • A folder is shown dimmed: it no longer exists. Clicking it asks whether to remove it
  • Ctrl+Shift+F does nothing: it may clash with another app's key (VS Code, for example). Change it under Shortcut in the Settings tab
  • Flagged by antivirus software: a false positive, reported to Microsoft
  • Your history, favorites and settings stay on this PC and are never sent anywhere (only the Store license check talks to Microsoft). See the Privacy Policy
