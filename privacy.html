Foldex プライバシーポリシー

omake works（以下「当方」）は、Windows アプリケーション「Foldex」（以下「本アプリ」）における 利用者の情報の取り扱いについて、以下のとおり定めます。

1. 外部への送信について

本アプリは、インターネット通信を行いません。利用者の情報を当方や第三者へ送信することは 一切ありません。広告・アクセス解析・クラッシュレポートの送信機能も含んでいません。

2. 本アプリが PC 内に保存する情報

本アプリは、機能の提供のために次の情報を利用者の PC 内にのみ保存します。

種類内容
履歴ファイルダイアログで開いたフォルダのパス（最大 100 件）と、そのダイアログを表示したアプリの実行ファイル名
お気に入り利用者が登録したフォルダのパス、グループ名、並び順、色
設定表示サイズ、表示言語、表示位置、ショートカットキーなど
動作ログ不具合調査のための記録（起動・終了の時刻、操作したフォルダのパス、ウィンドウの情報）

フォルダのパスには、Windows のユーザー名が含まれることがあります （例: C:\Users\ユーザー名\Documents）。これらは PC の外に出ることはありません。

3. 保存場所

  • Microsoft Store 版: Windows がアプリごとに用意する保存場所
  • Python 版（社内配布・開発用）: %APPDATA%\Foldex\

4. 情報の削除

  • 履歴は、本アプリの「設定」タブの「履歴をクリア」で削除できます。
  • お気に入りは、一覧から個別に削除できます。
  • Microsoft Store 版をアンインストールすると、保存された情報も削除されます。 ただし、以前のバージョン（Python 版など）が作成した %APPDATA%\Foldex\ が残っている場合、 そのフォルダはアンインストールでは削除されません。手動で削除してください。

5. 購入に関する情報

本アプリの購入・支払い・返金は Microsoft Store が取り扱います。当方が利用者の氏名・住所・ クレジットカード情報などを受け取ることはありません。

6. 第三者への提供

当方は、利用者の情報を保有していないため、第三者へ提供することはありません。

7. 本ポリシーの変更

本ポリシーを変更する場合は、このページを更新します。

8. お問い合わせ

omake.works@gmail.com

Foldex Privacy Policy

This policy explains how the Windows application "Foldex" (the "App"), published by omake works ("we"), handles your information.

1. No data leaves your PC

The App does not use the internet. It never sends any information to us or to anyone else. It contains no advertising, analytics, or crash-reporting functionality.

2. What the App stores on your PC

To do its job, the App stores the following on your PC only.

TypeContents
HistoryPaths of folders opened in file dialogs (up to 100) and the file name of the application that showed the dialog
FavoritesFolder paths you add, group names, order, and colors
SettingsFont size, display language, panel position, shortcut keys, and similar
LogRecords kept for troubleshooting (start/stop times, folder paths used, window information)

Folder paths may contain your Windows user name (for example, C:\Users\YourName\Documents). This information never leaves your PC.

3. Where it is stored

  • Microsoft Store version: the storage Windows sets aside for the app
  • Python version (in-house / development): %APPDATA%\Foldex\

4. Deleting the information

  • Clear the history from "Clear History" on the App's Settings tab.
  • Remove favorites individually from the list.
  • Uninstalling the Microsoft Store version deletes the stored information. If a %APPDATA%\Foldex\ folder created by an earlier version (such as the Python version) remains, uninstalling does not remove it; delete that folder manually.

5. Purchases

Purchases, payments, and refunds are handled by the Microsoft Store. We never receive your name, address, credit card details, or similar information.

6. Sharing with third parties

We hold no information about you, so there is nothing to share with third parties.

7. Changes to this policy

If this policy changes, this page will be updated.
